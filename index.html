Configuración inicial

Completa estos pasos una sola vez antes de compartir la prueba con los candidatos.

Paso 1 · Crea la hoja de Google Sheets

  1. Ve a sheets.google.com → crea una nueva hoja llamada Resultados Interns 2027.
  2. En la fila 1 deja los encabezados en blanco; el script los creará automáticamente al primer envío.

Paso 2 · Crea el Apps Script

  1. Dentro de la hoja: menú Extensiones → Apps Script.
  2. Borra el contenido del editor y pega este código:
const SHEET_NAME = "Respuestas"; const CODES_SHEET = "Codigos"; // hoja con códigos válidos function doPost(e) { try { const ss = SpreadsheetApp.getActiveSpreadsheet(); // --- hoja de respuestas --- let sheet = ss.getSheetByName(SHEET_NAME); if (!sheet) sheet = ss.insertSheet(SHEET_NAME); const data = JSON.parse(e.postData.contents); const flat = flattenObject(data); if (sheet.getLastRow() === 0) { sheet.appendRow(["Timestamp", ...Object.keys(flat)]); } sheet.appendRow([new Date().toISOString(), ...Object.values(flat)]); // --- marcar código como usado --- let codesSheet = ss.getSheetByName(CODES_SHEET); if (codesSheet) { const codes = codesSheet.getDataRange().getValues(); for (let i = 1; i < codes.length; i++) { if (String(codes[i][0]).trim().toUpperCase() === String(data.codigo || "").trim().toUpperCase()) { codesSheet.getRange(i + 1, 2).setValue("USADO"); break; } } } return ContentService .createTextOutput(JSON.stringify({ ok: true })) .setMimeType(ContentService.MimeType.JSON); } catch(err) { return ContentService .createTextOutput(JSON.stringify({ ok: false, error: err.message })) .setMimeType(ContentService.MimeType.JSON); } } function doGet(e) { const ss = SpreadsheetApp.getActiveSpreadsheet(); let codesSheet = ss.getSheetByName(CODES_SHEET); if (!codesSheet) { return ContentService .createTextOutput(JSON.stringify({ valid: false, reason: "no_codes_sheet" })) .setMimeType(ContentService.MimeType.JSON); } const code = String(e.parameter.code || "").trim().toUpperCase(); const rows = codesSheet.getDataRange().getValues(); for (let i = 1; i < rows.length; i++) { if (String(rows[i][0]).trim().toUpperCase() === code) { const usado = String(rows[i][1]).trim().toUpperCase() === "USADO"; return ContentService .createTextOutput(JSON.stringify({ valid: true, used: usado })) .setMimeType(ContentService.MimeType.JSON); } } return ContentService .createTextOutput(JSON.stringify({ valid: false })) .setMimeType(ContentService.MimeType.JSON); } function flattenObject(obj, prefix) { prefix = prefix || ""; return Object.keys(obj).reduce((acc, k) => { const pre = prefix ? prefix + "." + k : k; if (typeof obj[k] === "object" && obj[k] !== null && !Array.isArray(obj[k])) { Object.assign(acc, flattenObject(obj[k], pre)); } else { acc[pre] = Array.isArray(obj[k]) ? obj[k].join(" | ") : obj[k]; } return acc; }, {}); }
  1. Haz clic en Implementar → Nueva implementación.
  2. Tipo: Aplicación web · Ejecutar como: Yo · Acceso: Cualquier usuario.
  3. Copia la URL que aparece (Web App URL) — la necesitarás en el Paso 4.

Paso 3 · Crea la hoja de códigos

  1. En el mismo Google Sheet crea una segunda pestaña llamada Codigos.
  2. Columna A: codigo (encabezado) + un código por fila, p. ej. AS2027-001.
  3. Columna B: estado (encabezado) — déjala vacía; el script la llena automáticamente.

Paso 4 · Conecta el HTML con tu Sheet

  1. Abre este archivo HTML en un editor de texto.
  2. Busca la línea const APPS_SCRIPT_URL = "PEGA_TU_URL_AQUI";
  3. Reemplaza PEGA_TU_URL_AQUI con la URL copiada en el Paso 2.
  4. Guarda el archivo y compártelo con los candidatos.
